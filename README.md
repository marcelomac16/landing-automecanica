# Landing Page - Mecânica Forte

Landing page moderna de uma automecânica com botão de direcionamento para WhatsApp.

## Como ver

Abra o arquivo `index.html` no navegador ou use GitHub Pages.

## Personalização

- Troque o número do WhatsApp (`5511999999999`) pelo número real.
- Altere textos, cores e serviços conforme necessário.

Projeto criado para aprendizado de HTML, CSS e Git.
